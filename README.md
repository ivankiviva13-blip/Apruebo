# Permiso B Quest — v1.3

Progressive Web App de práctica para el permiso B.

## Cambios v1.3
- Tema 3 — El estado del conductor ampliado con siete mini-lecciones bilingües.
- Diez preguntas situacionales originales en español, con tres opciones y explicación tras responder.
- Infografía del proceso percepción → reacción → decisión y matriz de riesgos (fatiga, alcohol/drogas, medicamentos y distracciones).
- Separación explícita entre contenido del manual DGT 2024 y actualización oficial DGT de noviembre de 2026.
- Enlaces oficiales sobre alcohol, sueño/cansancio y drogas/medicación.

## Base y límites
- Manual del Permiso B en Lectura Fácil, DGT / ETRASA, edición corregida octubre de 2024, Tema 3, páginas impresas 42–66.
- Actualización DGT: https://www.dgt.es/muevete-con-seguridad/evita-conductas-de-riesgo/consumo-de-alcohol/
- Descanso y somnolencia: https://www.dgt.es/muevete-con-seguridad/evita-conductas-de-riesgo/Conducir-con-sueno-o-cansancio
- Drogas y medicación: https://www.dgt.es/muevete-con-seguridad/evita-conductas-de-riesgo/consumo-de-drogas-y-medicacion/
- Las preguntas son originales de práctica inspiradas en el estilo DGT; no son preguntas oficiales ni filtradas.
- El curso completo de 18 unidades aún no está desarrollado exhaustivamente. Temas 1, 2 y 3 ampliados; el resto debe completarse progresivamente.

## Uso
Descomprime el ZIP y sirve la carpeta mediante HTTPS para instalarla como PWA en iPhone (Safari → Compartir → Añadir a pantalla de inicio). El progreso se guarda localmente en el navegador/dispositivo.
